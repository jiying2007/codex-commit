# Quality Platform

Codex Commit Safe 4.1 consumes Safe Core 4.4 Impact Signals as bounded, deterministic evidence for existing scope inference. The Commit product does not expose Review profiles, SARIF execution, or auto-fix because those are not commit-message responsibilities.

Impact Signals only strengthen existing path/diff scope hints; they never override strict scope policy, Safe Contract, staged-snapshot checks, Commit Receipt v4, or user-selected language/style constraints. Token-aware semantic context and model routing remain unchanged.
